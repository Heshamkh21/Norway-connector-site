1. What the connector processes

When an authorised user connects QuickBooks and selects a date range, the connector reads company identity and relevant preferences, then invoices or credit notes. Imported records may include document IDs and numbers, dates, customer names and identifiers, email/postal addresses, line descriptions, quantities, prices, currencies, tax, totals, balances, private notes, linked transactions and additional fields included in the original API record.

The local workspace also stores connection settings and tokens, a workspace username and password hash, session information, user-entered PO/buyer/end-customer references where used, review decisions, timestamps, fingerprints, action reasons and audit records. Sandbox features additionally store their test-pack, test-order and delivery-status records. Technical diagnostics are designed to omit secrets and raw provider error bodies; users should not put secrets in free-text fields.

2. Why it is used

Data is used for authorised internal finance review, comparing imports with QuickBooks, maintaining review/audit history, managing connections and testing the separate fictional sandbox workflow. The connector has no advertising, data-sale or AI-analysis feature and does not send its records to OpenAI or another AI service.

3. Where it is stored and security limitations

The installed application binds to the local computer's loopback interface. Its working data, credentials and tokens are stored in the local .local folder. The public setup website does not host the invoice workspace or its database.

The app hashes the workspace password and uses session and form protections. The local workspace uses a session cookie for authentication and form protection. However, its invoice database, credentials and token files are not encrypted at rest by the application. Protect them using company-approved device access, disk encryption and backup arrangements. The connector does not establish or verify those company/device controls. Browser access to the local workspace uses HTTP on localhost; external provider API calls use HTTPS with certificate verification.

4. External services and disclosures

  • Intuit/QuickBooks: provides authentication and the selected accounting records. The production accounting connection makes reads only; OAuth token exchange and refresh are separate requests to Intuit.
  • Billit and Peppol sandbox: used only for the separately generated fictional test workflow and its configured sandbox seller/recipient details. Explicit test actions can create sandbox records or request sandbox delivery. Real production imports are not sent to Billit, Peppol or customer email by this connector. Test copies can also include user-entered PO/buyer references; users must not enter real customer data into fictional tests. Billit may issue account notifications under its own settings.
  • GitHub Pages: hosts the public setup pages. Those pages have no credential forms, analytics scripts or invoice data and do not automatically access the local app. GitHub may process IP addresses and browser/request metadata to operate its hosting service, under its own privacy notice.

The app does not automatically upload local invoice files or databases to the public website. Any device backups, file syncing, support sharing or exports performed outside the connector are subject to the company's separate controls. The operator should confirm provider and device locations before making any data-residency or international-transfer statement.

5. Retention, deletion and disconnecting

There is no automatic deletion timer for the connector's documents or audit history. Local data remains until removed by an authorised user or under the company's retention process. This notice does not introduce a fixed retention period that the software does not enforce.

Deleting a local document removes that imported working copy, not the original in QuickBooks. Audit entries may retain document numbers/IDs, reviewer usernames, timestamps, references, action details and reasons. Test-operation records and backups may also remain. Re-importing can restore a previously deleted document.

Removing the local live connection deletes its saved production tokens and company confirmation, while imported records and audit history remain. Revoke Intuit authorisation separately using QuickBooks' connected-app controls. Removing local tokens does not itself call Intuit's revocation API.
